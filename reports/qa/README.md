# QA reports

Store repository-retained QA evidence under `reports/qa/YYYY-MM-DD/` and use a
descriptive filename tied to the audited surface. Reports must state their date,
scope, method, mutation boundary, and any unverified areas.

Screenshots belong beside the report only when they are persistently captured
and referenced by it. Ephemeral browser output, Playwright HTML reports, traces,
test results, and temporary exports remain generated artifacts and must not be
copied into this directory.
